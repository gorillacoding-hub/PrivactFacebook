# Usage

1. Build and install `privacyfblite.apk`
2. Open **PrivacyFBLite Settings** from the launcher
3. Change toggles
4. Tap **Apply & Restart App**
5. Use Facebook Lite as usual (messaging kept)

To open settings later: same second icon, or:

```bash
adb shell am start -a com.privacyfblite.SETTINGS
```
