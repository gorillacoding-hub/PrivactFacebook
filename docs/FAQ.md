# FAQ

**Does this remove the News Feed completely?**  
It disables ranking/feed paths and related modules. Facebook Lite still loads some UI from the server (Bloks); residual empty or partial feed surfaces can remain.

**Do messages still work?**  
Yes — msys / msysinfra / rtc stay enabled.

**Is tracking fully gone?**  
Telemetry paths, analytics plugins, Profilo, falco configs, and ad IDs are blocked or wiped. Meta can introduce new endpoints in updates.

**Legal?**  
You must supply your own APK. Do not redistribute a patched APK containing proprietary code without a legal basis.
